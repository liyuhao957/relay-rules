# Relay Implement

1. Restate the observable outcome and locate its entry point.
2. Read only the code and configuration needed to trace that path.
3. Check the working tree and preserve unrelated changes.
4. Make the smallest coherent implementation, including relevant errors and cleanup.
5. Run the narrowest check that proves the behavior; expand only when the affected boundary demands it.
6. Report changed files, observed verification, and remaining uncertainty.
